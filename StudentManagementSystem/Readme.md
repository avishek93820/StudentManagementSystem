# Student Management System (C# Console Application)

A simple **Student Management System** built using **C# and .NET Console Application**. This project demonstrates fundamental programming concepts such as Object-Oriented Programming (OOP), CRUD operations, collections, loops, conditionals, and console-based user interaction.

---

## Features

✅ Add new student records  
✅ View all student details  
✅ Search student by ID  
✅ Delete student records  
✅ Interactive menu-driven interface  
✅ Beginner-friendly clean code structure  

---

## Technologies Used

- C#
- .NET SDK
- Console Application
- Object-Oriented Programming (OOP)
